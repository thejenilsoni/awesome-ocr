# Docling

Docling by IBM simplifies document processing, parsing diverse formats — including advanced PDF understanding — and providing seamless integrations with the GenAI ecosystem. It supports PDF, DOCX, PPTX, XLSX, images, HTML, EPUB, and more.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python docling_ocr.py <path_to_document> [format: markdown|html|json]
```
